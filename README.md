# Amazon Clone

A frontend clone of the Amazon website built to practice and demonstrate web development skills.

## 🚀 Features

- Responsive design
- Navigation bar
- Product sections
- Product cards
- Footer section
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
